## 方法清单（24 种）

### A. 路由/裁剪 — 源头减量（7 种）
1. 静态路由：固定模板分配，无适应性
2. 全上下文广播：完整历史逐层传递（爆炸根源，勿用）
3. RCR-Router：角色+阶段感知，token 预算分配相关子集
4. DACS：非对称隔离（Registry ≤200 token 摘要 / Focus 完整上下文）
5. Agent-Radar：注意力权重引导，空间/时间/语义三层衰减
6. 动态上下文路由（RAG）：按需检索注入 Top-K
7. 滑动窗口：只保留最近 N 轮

### B. 压缩/出窗 — 存量瘦身（10 种）
8. 被动摘要：溢出后总结旧消息替换（故障发生才处理）
9. 主动自主压缩（Focus）：Agent 自主 consolidate+withdraw，锯齿模式
10. 递归/分层摘要：多级摘要金字塔，按需下钻
11. 上下文编排器（ACE）：可逆三段式，按任务状态弹性装配
12. TokenPilot 局部驱逐：生命周期监控，相关性过期才 offload
13. TokenPilot 入口压缩：ingestion 网关稳定前缀，保 prompt cache
14. 代码执行模式：中间数据进沙箱，只回传高密度摘要（-99%）
15. 可逆驱逐（回执+recall_result）：删正文留回执，需要时拉回
16. 截断策略：最简直接丢弃（不可逆）
17. 外部压缩模型（LLMLingua）：独立小模型压 prompt

### C. 结构化/架构 — 根本解（7 种）
18. 存储与呈现分离（ADK 四层）：Working/Session/Memory/Artifacts
19. 三层缓冲：active + 滚动摘要 + on-demand retrieval + memory
20. 输出过滤门卫：工具/API 返回先整形再进窗口
21. 上下文变量（durable state）：显式可覆写状态，不依赖历史
22. KV-Cache 复用（KVCOMM）：计算复用，7.8x 提速
23. 工具渐进披露：工具 schema 按需加载
24. 提前阈值压缩：窗口 65% 触发，防被动溢出

## 关键洞察

- 一切可验证性前提：**存储与呈现分离**——压缩/出窗必须以"原始内容外部留存 + 句柄可召回"为底座。
- 可逆性分级：完整可找回（1,2,3,4,5,6,10H,11,12,13,14,15,18,19,20,23）｜部分（8,9,10L,17,21）｜不可找回（7,16）。
- 对抗"缓存失效"新矛盾：TokenPilot 指出乱裁剪破坏前缀 → prompt cache 失效，压缩需保持前缀稳定。
- 主动优于被动：Focus 频繁压缩（6 次/任务）token 收益大而准确率不变；被动等溢出是为时已晚。
