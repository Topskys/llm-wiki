# Project Sid

## 核心结论

Project Sid 是 Altera 在 Minecraft 中开展的长程文明涌现实验：据综述收录与公开报道，数百到上千个智能体长期共存，涌现出分工、交易、宗教与税收治理等文明构件，把沙盒环境的复杂度与组织结构做到了最深 [[4]](#ref-4)。其官方技术报告暂无公开可点链接，引用时应注明来源性质。

## 要点拆解

### 规模谱系定位

千级规模、Minecraft 环境：环境层不是社交媒体也不是小镇，而是带经济与物理约束的开放世界，研究目标是「机制设计、协作演化」——观察一群智能体如何长出治理结构。

### 文明构件

实验据称涌现出四类文明构件：分工（职业分化）、交易（经济行为）、宗教（共同信念）、税收治理（制度雏形）。若成立，这是「社会像不像社会」这一维度上走得最远的证据，但证据等级低于可公开复现的 arXiv 实验 [[4]](#ref-4)。

### 引用纪律

这是一个「来源性质需注明」的案例：综述收录 + 公开报道 ≠ 官方可复现报告。知识库层面保留其谱系位置（表 2），但在下任何机制设计结论前，应先找替代来源交叉验证，不存在时明确标注【推导】或传闻性质。
