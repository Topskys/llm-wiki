# Generative Agents

## 核心结论

Generative Agents 是斯坦福 2023 年的开山实验与平台：25 个 LLM 智能体在 Smallville 沙盒小镇自主生活，没有任何脚本编排，它们自行传播信息、形成关系，还自发组织了一场情人节派对 [[1]](#ref-1)。涌现行为的真实性第一次在 LLM 智能体身上得到验证，大规模智能体仿真的大门由此打开。

## 要点拆解

### 立论意义

在它之前，社会仿真被两堵墙卡住：规则只能复现已知规律，且建模成本以月计。这个实验证明了生成式智能体对没预设过的情境也能给出合理反应——「涌现」从需要奇迹变成默认产物，直接定义了整个领域的范式。

### 规模定位

表 2 谱系中规模最小（25 个），但贡献是验证机制而非性能：它把「行为可信度」与「信息传播」立成了后续所有平台的评价维度，Smallville 沙盒开源后成为领域的公共参照系。

### 研究能力反哺

其记忆-反思的智能体设计是 [[数字居民]] 五件套的直接来源，也构成了 [[数字分身]] 第二代复刻的技术底座 [[2]](#ref-2)。
