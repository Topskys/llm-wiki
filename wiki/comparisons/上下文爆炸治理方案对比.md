# 上下文爆炸治理方案对比

## 核心结论

上下文爆炸的根源是**把不该进上下文的内容塞进了窗口**。治理方案三大类：**路由/裁剪**（源头少进）、**压缩/出窗**（存量瘦身）、**结构化/架构**（根本解）。2026 年共识：**把窗口当预算分配，而不是当天花板撞**。能否在冲突时找回原始历史验证，取决于是否遵循「存储与呈现分离」——压缩只允许发生在可恢复的内容上。

```mermaid
    B --> E["C 结构化/架构<br/>根本解"]
    C --> C1["静态路由 / RAG路由<br/>RCR-Router / DACS"]
    D --> D1["主动自主压缩<br/>可逆驱逐 / 回执召回"]
    E --> E1["存储与呈现分离<br/>ADK四层 / 三层缓冲"]
    E2["可验证性底座"] -.-> C1
    E2 -.-> D1
```

# A 组：路由/裁剪（7 种）

## A1. 静态路由

```mermaid
graph LR
    A["任务输入"] --> B["路由表<br/>固定模板"]
    B --> C["组装 prompt<br/>system + 任务模板"]
    C --> D["LLM 执行"]
    D --> E{"结果冲突?"}
    E -->|"否"| F["完成"]
    E -->|"是"| G["直接对比模板<br/>查脚本输入"]
```

**实现**：启动时按固定模板拼 prompt。**加载回**：无加载，内容常驻。**冲突验证**：模板即原始，直接对比。

## A2. 全上下文广播

```mermaid
graph LR
    A["根 Agent"] --> B["完整 history 数组"]
    B --> C["子 Agent A"]
    B --> C2["子 Agent B"]
    B --> C3["子 Agent C"]
    C --> D["继续透传下一代"]
    C2 --> D
    C3 --> D
    D --> E["token 指数增长<br/>爆炸源"]
```

**实现**：完整 message 原样传给所有子 Agent 并逐层透传。**加载回**：无删除故无需加载（也正是代价）。**冲突验证**：历史天然完整，验证最容易、成本最高。**不推荐**。

## A3. RCR-Router

```mermaid
graph LR
    A["路由层"] --> B["外部存储<br/>全部原始历史"]
    B --> C["角色定义 + 阶段状态"]
    C --> D["按 token 预算<br/>选取相关子集"]
    D --> E["组装 prompt"]
    E --> F["LLM 执行"]
    F --> G{"冲突?"}
    G -->|"是"| H["重放完整历史<br/>比对路由裁剪是否丢信息"]
```

**实现**：路由层按角色+阶段从外部存储选相关子集，被剪内容留在外部。**加载回**：每次调用按相关度重新召回子集（可累积可回滚）。**冲突验证**：外部存储保留全部原始，重放完整历史比对是路由剪枝丢信息还是模型误判。

## A4. DACS 非对称隔离

```mermaid
graph LR
    A["编排器"] --> B{"模式?"}
    B -->|"Registry"| C["每 Agent ≤200 token 摘要<br/>监控全部 Agent"]
    B -->|"Focus(ai)"| D["被请求 Agent 完整上下文<br/>其余 Agent 压为摘要"]
    C --> E["按需触发切换"]
    D --> E
    E --> F{"冲突验证?"}
    F -->|"是"| G["对该 Agent 掉回 Focus<br/>确定性重载原始上下文 F(ai)+R-i"]
```

**实现**：Registry（摘要监控）+ Focus（完整上下文，子线性与 N 无关）。**加载回**：Focus 切换 = 从原始存储按需物化完整上下文。**冲突验证**：原始上下文确定性构造留存，单 Agent 掉回 Focus 复查，隔离验证不污染其他 Agent。

## A5. Agent-Radar 注意力引导

```mermaid
graph LR
    A["监控注意力权重"] --> B["空间/时间/语义三层衰减评分"]
    B --> C{"相关度低?"}
    C -->|"是"| D["移出窗口到外部 buffer"]
    C -->|"否"| E["保留在窗口"]
    D --> F["注意力回升时重新注入"]
    F --> G{"冲突验证?"}
    G -->|"是"| H["按时间戳从 buffer 回放原始对话"]
```

**实现**：按三层衰减打分，低相关 token 软移出。**加载回**：注意力信号回升再注入。**冲突验证**：外部 buffer 按时间线保存，可回放；但无显式索引，定位依赖时间戳。

## A6. 动态路由 RAG

```mermaid
graph LR
    A["历史/知识"] --> B["向量化入库<br/>向量数据库"]
    B --> C["每轮 query"]
    C --> D["Top-K 检索"]
    D --> E["重排序 + 注入"]
    E --> F["LLM 执行"]
    F --> G{"冲突?"}
    G -->|"是"| H["按检索 id 复核原始 chunk"]
```

**实现**：历史向量化，query 检索 Top-K 注入，不检索不进窗口。**加载回**：检索即加载。**冲突验证**：原始全量在向量库，任意冲突可检索原始 chunk 复核；注意记录检索 id，防缺失召回无法追溯。

## A7. 滑动窗口

```mermaid
graph LR
    A["完整消息流"] --> B["窗口<br/>最近 N 轮"]
    B --> C["LLM 执行"]
    A --> D["更早消息<br/>物理删除"]
    D --> E{"冲突需要验证?"}
    E -->|"是"| F["不可找回<br/>仅靠窗口外提前归档的日志"]
```

**实现**：只保最近 N 轮，更早删除。**加载回**：无。**冲突验证**：不可找回；若要验证需在截断前把旧历史导出到日志/DB 做窗口外审计。

# B 组：压缩/出窗（10 种）

## B1. 被动摘要

```mermaid
graph LR
    A["上下文持续增长"] --> B{"token 超阈值?"}
    B -->|"否"| C["继续累积"]
    B -->|"是"| D["触发 LLM 摘要调用"]
    D --> E["总结旧半段消息"]
    E --> F["摘要替换旧消息<br/>保留最近 K 条"]
    F --> G["进入下一步"]
    G --> H{"内存/另一拷贝存原文?"}
    H -->|"是"| I["按 id 找回原文复核"]
    H -->|"否"| J["原文丢失<br/>摘要曲解无法核验"]
```

**实现**：溢出 → 一条 LLM 调用总结旧片段替换（如 summary_ratio=0.3、preserve_recent=10）。**加载回**：摘要直接占位。**冲突验证**：摘要本身不可逆；若实现时原文归档到旁路存储（STM/DB）可按消息 id 找回；多数开源实现只留摘要 → **丢失**。

## B2. Focus 主动自主压缩

```mermaid
graph LR
    A["Agent 探索"] --> B{"子任务完成<br/>或遇死路?"}
    B -->|"是"| C["complete_focus<br/>生成尝试+所学+结果"]
    C --> D["追加到顶部 Knowledge 块"]
    D --> E["删除 checkpoint 至当前<br/>原始消息"]
    E --> F["上下文回到锯齿低谷"]
    F --> G["后续需要旧经验?"]
    G -->|"是"| H["从外部存档召回"]
    G -->|"否"| I["继续基于 Knowledge 运行"]
    H --> J{"冲突验证?"}
    J -->|"是"| K["Knowledge + 外部原始归档<br/>双重核对"]
```

**实现**：Agent 自主决定 consolidate（并入 Knowledge 块）+ withdraw（删除原始历史）；配合"每 10-15 次工具调用压缩"激进提示，SWE-bench token -22.7% 准确率持平。**加载回**：Knowledge 常驻顶部；需旧经验可从外部存档召回。**冲突验证**：有召回路径；但删除是真实的（pylint-7080 曾因误删有效上下文重探索），须 Knowledge+外部原始双重核对。

## B3. 递归/分层摘要

```mermaid
graph LR
    A["原始消息"] --> B["L1 语句摘要"]
    B --> C["L2 段落摘要"]
    C --> D["L3 会话摘要"]
    D --> E["窗口只放浓缩层"]
    E --> F{"需要细节?"}
    F -->|"是"| G["向下钻一层"]
    G --> H["最底层 = 原始消息"]
    H --> I{"冲突验证?"}
    I -->|"是"| J["逐层下钻<br/>定位哪层曲解"]
    D --> K["底层被裁?"]
    K -->|"是"| L["降级为部分找回"]
```

**实现**：多级金字塔，窗口只放顶端浓缩层。**加载回**：按层级下钻。**冲突验证**：底层原文在则可逐层定位"哪层曲解"；底层被裁则降级部分找回。

## B4. ACE 上下文编排器

```mermaid
graph LR
    A["任务状态"] --> B["上下文编排层"]
    B --> C["Trajectory 段"]
    B --> D["Working 段"]
    B --> E["History 段"]
    C --> F["按状态弹性装配"]
    D --> F
    E --> F
    F --> G["主 LLM 收到紧凑上下文"]
    G --> H{"需要旧内容?"}
    H -->|"是"| I["按 undo 链还原段"]
    H -->|"否"| J{"冲突验证?"}
    I --> J
    J -->|"是"| K["还原轨迹逐段比对"]
```

**实现**：三段式按任务状态装配，压缩记录 undo 信息，**可逆**。**加载回**：编排器按需 swap 段。**冲突验证**：压缩生成还原轨迹，按 undo 链恢复原始上下文逐段比对（不依赖截断/一次性摘要）。

## B5. TokenPilot 生命周期驱逐

```mermaid
graph LR
    A["上下文片段"] --> B["生命周期监控<br/>剩余效用评估"]
    B --> C{"相关性过期?"}
    C -->|"否"| D["保留（保守）"]
    C -->|"是"| E["整段 offload 外部存储<br/>记录 起止索引+摘要+位置"]
    E --> F{"需要该段?"}
    F -->|"是"| G["按驱逐清单重新装载"]
    F -->|"否"| H{"冲突验证?"}
    G --> H
    H -->|"是"| I["装载原始段重放比对"]
```

**实现**：乘务相关性剩余效用，过期才整段 offload；batch 粒度保证可恢复完整性。**加载回**：按时间戳/key 召回。**冲突验证**：驱逐清单记录位置，按清单重新装载原始段重放。可找回。

## B6. TokenPilot 入口压缩

```mermaid
graph LR
    A["外部输入"] --> B["Ingestion 网关<br/>压掉环境噪声"]
    B --> C["稳定 prompt 前缀"]
    C --> D["prompt cache 命中"]
    D --> E["零成本加载"]
    A --> F["网关原文日志"]
    F --> G{"冲突验证?"}
    G -->|"是"| H["查 ingestion 日志"]
```

**实现**：ingestion 网关压掉开放环境噪声，保证前缀稳定 → prompt cache 命中。**加载回**：前缀稳定即缓存命中，加载近零成本。**冲突验证**：被压噪声不进历史，网关留原文日志可查。可找回。

## B7. 代码执行模式

```mermaid
graph LR
    A["MCP/工具原始数据"] --> B{"走 LLM?"}
    B -->|"否"| C["沙箱执行代码<br/>数据处理留在沙箱"]
    C --> D["只回传最终高密度摘要<br/>(-99% token)"]
    D --> E["进上下文"]
    E --> F{"需要原始数据?"}
    F -->|"是"| G["调沙箱查询接口按需取"]
    F -->|"否"| H{"冲突验证?"}
    G --> H
    H -->|"是"| I["沙箱重算数据流<br/>比对结果一致性"]
```

**实现**：中间数据用代码在沙箱处理，agent 只收最终摘要（~75k→600 token）。**加载回**：结果进窗；原始数据沙箱按需查询。**冲突验证**：原始全程在沙箱/DB，重算相同数据流比对一致性，沙箱=单点事实源。可找回。

## B8. 可逆驱逐（回执 + recall）

```mermaid
graph LR
    A["待驱逐消息"] --> B["生成回执<br/>名 + 摘要args + outcome摘要 + recall_result(id)"]
    B --> C["正文删除"]
    C --> D["Agent 需要原文?"]
    D -->|"是"| E["recall_result(id) 拉回"]
    D -->|"否"| F{"冲突验证?"}
    E --> F
    F -->|"是"| G["recall 拉原文对比"]
    F -->|"否"| H["若 recall 已不可用<br/>即驱逐决策越界，复盘"]
```

**实现**：删正文留回执（call/outcome 摘要+召回句柄）。**加载回**：需要时 `recall_result(id)` 重新拉取。**冲突验证**："仅删除可恢复内容"是驱逐正确性判据；拉原文对比，recall 失败=驱逐越界需复盘。**可逆**。

## B9. 截断策略

```mermaid
graph LR
    A["完整上下文"] --> B["截断<br/>丢弃远端内容"]
    B --> C["LLM 执行"]
    A --> D{"冲突需要验证?"}
    D -->|"是"| E["不可找回<br/>除非截断前归档"]
```

**实现**：最粗暴，直接丢弃。**加载回**：无。**冲突验证**：不可找回，除非截断前有归档。**不可逆**。

## B10. 外部压缩模型（LLMLingua）

```mermaid
graph LR
    A["原始 prompt"] --> B["独立小模型<br/>压缩 prompt"]
    B --> C["删除停用词/冗余句"]
    C --> D["压缩版进上下文"]
    A --> E{"自备原始?"}
    E -->|"是"| F["冲突时用原始对比"]
    E -->|"否"| G["压缩即丢失<br/>无法验证"]
```

**实现**：独立小模型压 prompt，不占主推理。**加载回**：压缩结果进窗。**冲突验证**：LLMLingua 输出即压缩版；验证需自行附存原始 prompt。部分。

# C 组：结构化/架构（7 种）

## C1. 存储与呈现分离（ADK 四层）

```mermaid
graph LR
    A["四层存储"] --> B["Working Context<br/>即时临时"]
    A --> C["Session<br/>持久交互日志"]
    A --> D["Memory<br/>跨会话长期知识"]
    A --> E["Artifacts<br/>大文件按名寻址"]
    B --> F["编译器从 Session 构建 Working 视图"]
    F --> G["每次调用重编译"]
    G --> H{"冲突验证?"}
    H -->|"是"| I["比对编译视图 vs<br/>Session 原始日志"]
```

**实现**：Working（临时视图）/Session（持久日志）/Memory（长期）/Artifacts（按名寻址）；Working 是 Session 编译的临时视图。**加载回**：每次调用由编译器从 Session 重建 Working；大文件点名 Artifacts。**冲突验证**：Session 唯一事实源，重编译视图即得，比对产物即可。**架构级可找回**。

## C2. 三层缓冲

```mermaid
graph LR
    A["active<br/>即时任务 + 最近工具输出"] --> D["LLM"]
    B["滚动会话摘要<br/>追加式更新"] --> D
    C["retrieval 层<br/>按需查询"] --> D
    E["memory<br/>跨会话"] --> A
    C --> F["记录检索的 chunk id"]
    F --> G{"冲突验证?"}
    D --> G
    G -->|"是"| H["摘要时间线<br/>逐 turn 下钻原始"]
```

**实现**：active + 滚动会话摘要 + 按需 retrieval + 跨会话 memory。**加载回**：retrieval 调用即加载；摘要追加式更新。**冲突验证**：滚动摘要与来源会话并存，冲突按时间线下钻原始 turn；检索层记录 chunk id 便于复核。可找回。
