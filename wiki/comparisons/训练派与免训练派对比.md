# 训练派与免训练派对比

## 核心结论

自适应推理的实现范式分两派：训练派把分配策略学进模型，上限高但要数据与训练资源，且策略偏移的风险与奖励标尺直接相关；免训练派零成本上线，但上限受制于底座已有能力。选型的核心权衡是「改不改模型」。

## 要点拆解

### 五维对照

| 维度 | 训练派 | 免训练派 |
|---|---|---|
| 手段 | RL 策略优化 / SFT 内化 / 轻量控制器 | prompt 控深 / 反馈终止 / 模块组合 |
| 是否改模型 | 是（策略进权重或外挂控制器） | 否（纯推理期编排） |
| 数据与成本 | 需可变推理长度标签或复合奖励的训练数据 | 零训练成本，即配即用 |
| 上限 | 高：分配策略可学到任务无关层面 | 受底座已有能力封顶 |
| 主要风险 | 策略偏移——风险与奖励标尺直接相关 | 只能选用旧行为，无法新增 |

### 各自的典型形态

- **训练派三支**：把计算分配作为策略动作、以任务性能加计算成本的复合奖励优化（RL）；用带可变推理长度或出口标签的数据做 SFT 让模型内化自适应行为；单独训练轻量模块预测出口时机、路由决策或推理长度（控制器，见 [[早退]] 的动态出口调度）；
- **免训练派三支**：prompt 指令直接控制推理深度（简要回答或详细推理）；用置信度、答案稳定性或熵等自身信号触发终止（信号见 [[难度信号]]）；推理时动态组合不同能力的模块按需调用。

### 选型决策

- 有训练预算且要长期收益：训练派，奖励标尺设计先行（防止「简单查询也往长想」的策略偏移）；
- 快速上线 / 每个模型都要适配：免训练派，先拿 prompt 控深 + 置信度终止兜底；
- 混合路线常见：底座出自我信号，外挂轻量控制器收决策，训练量集中在小模块【推导】。
