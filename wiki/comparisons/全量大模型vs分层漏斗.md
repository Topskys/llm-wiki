# 全量大模型vs分层漏斗

## 核心结论
- 分层漏斗将约 95% 的请求在毫秒级闭环，仅约 5% 长尾消耗大模型算力。
- 综合成本降低约 75-85%，同时因规则层与上下文层的确定性更高，整体准确率反而优于全量 LLM 方案。

## 对比表

| 维度 | 全量大模型 | 分层漏斗 |
|------|------------|----------|
| 平均延迟 | 2000ms | 50ms |
| 日均 GPU 成本 | 100% | 15-25% |
| 准确率 | 约 92% | 约 95% |
| 延迟构成 | 单次推理 2000ms 起步 | 规则层 <1ms + 上下文层 ~100ms + 大模型层 500-2000ms |
| 成本构成 | 所有请求消耗大模型 token | 仅 5% 长尾消耗大模型算力 |
| 稳定性 | 大模型存在幻觉，意图分类偶尔跑偏 | 规则层与上下文层确定性更高 |

## 要点拆解

### 全量大模型的三个硬伤
1. **延迟失控**：单次推理 2000ms 起步，P99 随并发线性恶化。
2. **成本爆炸**：简单指令也消耗 token，高峰期 GPU 开销超预算。
3. **稳定性风险**：大模型存在幻觉，意图分类偶尔跑偏。

### 分层漏斗的优势
- 规则层拦截约 60% 流量，完全不消耗大模型算力。
- 上下文层承接约 35% 流量，使用轻量小模型，成本远低于大模型。
- 大模型层仅处理约 5% 长尾，成本可控。
