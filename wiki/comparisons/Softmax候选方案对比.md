# Softmax候选方案对比

## 四条约束 × 四个候选

| 约束 | 线性归一化 | argmax | sigmoid | **softmax** |
|---|---|---|---|---|
| 每项 > 0 | ✗ 除完还有负数 | — | ✓ | ✓ 指数恒为正 |
| 总和 = 1 | ✓ | ✗ 输出是索引 | ✗ 各项独立、加总不为 1 | ✓ 归一化分母 |
| 保持相对强弱 | ✓ | ✗ 硬截断 | ✗ 独立处理、不保序 | ✓ 指数单调 |
| 可以训练 | ✓ | ✗ 没有梯度 | ✓ | ✓ 处处光滑可导 |
| 差分变比值 | ✗ | ✗ | ✗ | ✓ $z_i-z_j \to e^{z_i}/e^{z_j}$ |

## 核心结论

softmax 是**唯一同时通过四条约束的候选**，且独占**差分变比值**这一性质——logit 的加法直接对应概率的乘法，其他函数都不具备。因此它既不是可有可无的技巧，也不是经验凑出来的选择，而是被条件**逼出来的唯一自然解**。

各候选被淘汰的确切原因：

- **线性归一化**：归一化后仍可能出现负数，不构成概率分布。
- **argmax**：不可导，无法反向传播；softmax 因此被称为它的**可导软化版**。
- **sigmoid**：各项独立计算、彼此不知道对方的存在，加总不为 1，无法表示「多选一」的竞争关系。

softmax 还附带**指数放大差距**的福利，让微弱的打分差异在概率上变得显著，这正是输出层采样与注意力加权共同依赖的特性。
