# 早退与层跳过对比

## 核心结论

[[早退]]与[[层跳过]]同属动态深度，分水岭在「终止还是绕过」：早退在网络中间层设置出口，样本置信度足够时提前输出，需要中间分类器；层跳过直接让简单样本绕过部分层的执行，不需要中间分类器。取舍落在精度可控性与工程规整性之间。

## 要点拆解

### 六维对照

| 维度 | 早退 | 层跳过 |
|---|---|---|
| 动作 | 提前终止后续计算 | 绕过指定层执行 |
| 中间分类器 | 需要（判据本体） | 不需要（路由器替代） |
| 判据 | 置信度阈值 / 熵 / 边际 / 学习停止策略 | 路由决策（MoD 路由器） |
| 子类型 | 单出口 / 多出口 / 动态出口调度 | 按层路由映射 |
| 代表 | CALM [[1]](#ref-1) | Mixture-of-Depth [[2]](#ref-2) |
| 对硬件 | 友好：一次前向提前截断 | 破坏 batching 与 KV Cache 规整性 |

### 机制分野的解释

早退的出口判据本身就是难度信号（softmax 置信度等），信号失准直接表现为过早自信退出；层跳过把难度判断下沉到路由器训练，推理期不再依赖显式分类器，换取的是部署简化与路由质量上界。两支都可以再叠加动态路由（MoE）做宽度维度扩展【推导】。

### 选择建议

- 追求实现简单、显存规整、推理服务改造最小：早退（可从单出口起步）；
- 要更大计算节省且接受服务侧批处理改造：层跳过（MoD）；
- 两者共享同一个前置条件：难度信号先校准（见 [[难度信号]]），否则分别落到静默掉点与路由漂移（见 [[自适应失效模式]]）。
