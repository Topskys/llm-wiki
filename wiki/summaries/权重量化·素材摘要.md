# 权重量化·素材摘要

## 核心结论

《权重量化》梳理把 FP16/FP32 权重映射到 INT8/INT4/FP8 等低比特的完整知识面：基础原理、按对象与流程分类、六族主流算法、KV Cache 协同、工具链与 kernel、选型避坑与最小可运行示例。GPTQ、AWQ 是 INT4 推理常用方案，NF4 更适合微调，GGUF 适合本地部署，极限低比特靠 QuIP# 和 AQLM，工程上要避免把权重量化等同于等比例加速。

## 要点拆解

### 问题根源与基础原理

70B 模型 FP16 需约 140 GB HBM 超出单卡；量化动机是显存与带宽双瓶颈 [[1]](#ref-1)。核心矛盾是激活离群值——少数 hidden 维度幅值极端大，放大任何低比特量化误差。基础机制：仿射量化（scale + 零点）、对称/非对称、四种粒度（Per-tensor 到 Per-block + Super-block [[8]](#ref-8)）、静态/动态量化分工。

### 分类体系

- **按对象**：仅权重（W4A16 最普及）、权重+激活联合（W8A8/FP8 需过 SmoothQuant [[4]](#ref-4)）、KV Cache（长上下文可能反超权重，NVFP4 实测 3× TTFT 降 [[9]](#ref-9)）；
- **按流程**：PTQ（校准集离线、分钟到小时）vs QAT（伪量化 + STE、训练换极限精度，LSQ 代表）。

### 六族算法

LLM.int8 混合精度隔离离群 [[1]](#ref-1)；GPTQ Hessian 误差反馈至 175B 一次到位 [[2]](#ref-2)；AWQ 激活感知缩放保护 1% 显著权重、无需反向传播 [[3]](#ref-3)；SmoothQuant 等价变换把激活难度迁到权重、530B 单节点 [[4]](#ref-4)；QLoRA NF4 分位码本 + 双重量化 + 分页优化器，单卡 48GB 微调 65B [[5]](#ref-5)；QuIP# RHT 非相干 + E8 格码本 [[6]](#ref-6)、AQLM 加性量化 <3-bit Pareto 最优 [[7]](#ref-7)。

### 生态与工程

GGUF K-quants 超块双重量化，Q4_K_M 主流默认 [[8]](#ref-8)；Marlin 是 4-bit GEMM 主流 kernel [[12]](#ref-12)；bitsandbytes/AutoGPTQ/AutoAWQ/llama.cpp/vLLM/TensorRT-LLM/torchao 六套工具链场景分工 [[11]](#ref-11)。八条避坑：校准集分布、激活离群值、小模型敏感、混合精度算子保 FP、量化 ≠ 等比例加速、KV Cache 协同、GGUF 位宽按实测算、AWQ/GPTQ 按生态选。
