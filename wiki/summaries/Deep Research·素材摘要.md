# Deep Research·素材摘要

## 核心结论

素材的核心主张可压成三句：**判据是路径由谁决定**、**能力来自端到端强化学习而非手写流程**、**定位是初稿机器加线索地图而非答案机器**。

## 要点拆解

### 定义与判据

自主多步研究含四要素：自主规划、多步检索、交叉验证、可溯交付。判据只有一条——会不会自己决定下一步查什么。流程写死的二十轮流水线仍只是检索增强生成。

能力分层四档：L1 事实查询不该用、L2 单点问答不必用、L3 多源综述最适用、L4 决策结论只作输入。

### 必要性

普通问答的失效不在模型不够聪明，而在**检索预算**。单次检索只能覆盖所需证据的极小部分，放开轮次后完备度大幅提升，且与底座能力无关——这解释了官方内部评测中「允许调用工具次数越多、通过率越高」的现象。

三类需求的共同缺口是跨源比对、需追加检索、要长报告。

### 实现机制

| 机制 | 要点 |
|---|---|
| 端到端强化学习 | 训练任务即真实浏览与推理，习得规划、回退、转向；与手写流程的差别是泛化而非步骤多寡 |
| 五步执行链路 | 规划 → 检索 → 阅读 → 反思 → 综合，循环至材料足够，无固定轮次上限 |
| 上下文压缩 | 数十网页无法塞入窗口，必须提炼为证据笔记，直接决定耗时量级 |
| 引用归因 | 句子级引用才算可溯；错配最难发现、断链最常见、幻觉最危险 |
| 先追问 | 研究前澄清需求边界，成本远低于事后返工 |

### 评测与口径

HLE 26.6%、GAIA pass@1 67.36% 与 cons@64 72.57%、BrowseComp 首发未公布。最值得注意的是 Level 3 提升最大（42.31 → 58.03），即多步推理与跨源综合区间。

口径警示：分数依赖工具配置、尝试次数与题库版本，跨代际不可直接比较。

### 边界与风险

能做跨源综合、长报告、可溯源、数据计算；不能做实时性、墙后内容、权威性判断、替代人的判断。

三个风险：引用错配（最难发现）、成本时延（单次数十分钟）、评估口径不可比（自建域内小测集最实用）。
