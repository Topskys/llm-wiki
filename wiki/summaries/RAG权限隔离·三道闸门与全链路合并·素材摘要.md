# RAG权限隔离·三道闸门与全链路合并·素材摘要

## 核心结论

- **核心原则**：权限拦截放在数据层，不依赖大模型 Prompt 约束
- **三道闸门**：看不见（前置过滤）、说不出（后置校验）、标签不显（隐式权限向量）
- **全链路管控**：入库绑权限 → 检索前置过滤 → 上下文最小化 → 生成后置校验 → 缓存隔离 → 审计监控
- **配套机制**：动态权限同步、诱导提问防御、向量库选型与降级

## 要点索引

### 一、威胁模型（三类泄密路径）
- 明文泄露：无权 Chunk 被召回进入上下文
- 拼图式推导泄密：A、B 段单独合规、拼接后推导机密结论
- 权限标签侧信道泄露：明文密级标签暴露敏感信息存在性
- 诱导提问攻击：套话诱导模型拼接信息

### 二、第一道防线：检索前置过滤
- 文档入库绑定权限元数据，Chunk 继承权限标签
- 切片密级统一规范：同文档不同密级禁止混切
- prefilter 在相似度打分前物理剔除无权切片
- postfilter 导致漏斗坍塌（有权限内容被挤出 TopK）

### 三、第二道防线：生成后置内容校验
- 上下文最小化：二次校验 + 只给必要片段
- 直接泄露 vs 间接推理的风险区分
- 后置校验：解析输出文本、评估信息密度、脱敏/截断/拒答

### 四、第三道防线：隐式权限引用
- 明文标签的侧信道风险
- 隐式权限向量：权限编码成隐式向量嵌入切片内部
- 对外引用脱敏：不暴露密级、角色等权限元信息

### 五、配套工程机制
- 分层权限模型：租户/角色部门/用户白名单
- 缓存隔离：Key 绑定用户身份+权限
- 动态权限同步：事件驱动，秒级生效
- 审计与越权监控：全链路日志 + 后置校验拦截记录
- 诱导提问防御：意图识别模块拦截高危 query

### 六、向量库选型与降级
- Pinecone/Qdrant/Weaviate/Milvus/ChromaDB/pgvector/LanceDB 原生支持
- FAISS 不支持，降级为业务层白名单

### 七、段落/字段级权限细化
- 元数据增加 section_id/field_name 维度
- 同文档内差异化权限
