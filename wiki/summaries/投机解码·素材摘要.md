# 投机解码·素材摘要

## 素材定位

- **来源**：[[raw/papers/投机解码.md]]（单份论文素材，联网融合稿，含 6 篇参考文献）。
- **主题**：投机解码（Speculative Decoding）——不加改变输出分布的前提下加速 Decode 的推理优化。

## 核心要点

### 1. 问题与动机

- Decode 阶段逐 token 自回归、受**显存带宽**限制（memory-bound），每步只产出一个 token 却搬运全量权重，GPU 算力闲置。
- 核心洞察：**并行验证 K 个候选与逐一生成单个 token 成本几乎相同**（都要把权重读一遍）。

### 2. 机制：草稿-验证-重采样

- 草稿模型抢先起草 K 个候选 → 目标模型一次前向并行验证 → 按 `min(1,q/p)` 逐位接受 → 拒绝处从修正分布 `∝max(0,q-p)` 重采样。
- **无损由重采样保证**：每一步边缘分布恰为目标分布 q。

### 3. 六类草稿方案

独立草稿模型（Leviathan/Chen）/ 附加预测头（[[Medusa]]·[[EAGLE]]）/ 模型内置 [[MTP多Token预测]] / 无模型草稿（n-gram/Prompt-Lookup）/ 部分层 LayerSkip / 树形投机。

### 4. 工程落地

- 引擎：vLLM `--speculative-model`、SGLang `--speculative-algorithm EAGLE3`。
- 调参：草稿长度 K 4–8、树宽、验证预算。
- **接受率生命线**：40%–80% 健康、低于 50% 趋净负。
- 与量化/PagedAttention/CUDA Graph 正交叠加。

### 5. 实证与趋势

- Leviathan/Chen 原始方案：约 **2–3×** Decode 加速。
- EAGLE-3：五项任务最高 **6.5×**、较 EAGLE-2 提升约 1.4×、SGLang batch 64 下 1.38× 吞吐。
- 前沿：[[SpecForge]] 统一草稿训练流水线，DFlash/Domino 等新算法。
