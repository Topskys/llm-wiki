# 工业级AI意图识别架构·素材摘要

## 核心结论

- **核心原则**：不单一依赖大模型或传统分类模型，采用多分支混合识别
- **五模块架构**：输入预处理 → 多路并行识别 → 置信度聚合决策 → 后置校验过滤 → 样本回流迭代
- **串行 vs 并行**：高并发客服优先串行漏斗，复杂 Agent 优先多路并行

## 要点索引

### 一、传统 NLP vs 大模型意图识别
- 传统 BERT：固定少量意图，新增需重训，泛化差
- 大模型原生：不用标注，但 token 成本高、P99 延迟不可控、易幻觉

### 二、五模块混合架构
- 输入预处理：清洗/敏感词拦截/上下文读取/长度截断
- 多路并行识别：规则分支（毫秒级）/ 轻量模型分支（低成本）/ 大模型分支（高精度）
- 置信度聚合决策：阈值/多路投票/多意图/优先级
- 后置校验过滤：业务白名单 + 参数槽位校验
- 样本回流迭代：难例挖掘 + 增量微调

### 三、串行漏斗 vs 多路并行
- 串行：算力低但单点失效
- 并行：抗干扰强但算力高

### 四、四个工程坑
- 意图无限膨胀 → 意图合并，细粒度放槽位
- 没有置信度直接采信 → 配置阈值，低置信转人工
- 缺少回流机制 → 建立样本回流闭环
- 忽略上下文管理 → 读取会话上下文和槽位
