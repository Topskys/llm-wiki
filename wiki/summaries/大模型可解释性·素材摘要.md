# 大模型可解释性·素材摘要

## 核心结论

《大模型可解释性》主张：可解释性要求说明与真实计算过程一致，而不只是一段通顺理由；手段分四层且成本差异巨大，共享底线「观测只给相关性、因果只能靠干预」；最大实务要点是先做不依赖权重的留痕与复现，机制层是合规硬需求下才上的重装备。

## 要点拆解

### 概念与瓶颈

- **忠实性**：CoT 是生成的文本不是计算记录，注入偏置可让模型改答案却只字不提（BIG-Bench Hard 最多掉 36% [[5]](#ref-5)），监控有价值但脆弱 [[1]](#ref-1)——见 [[忠实性]]；
- **叠加与多义**：特征数远多于维度，单神经元混响几十个概念，直接读权重读不出语义 [[3]](#ref-3)，字典学习是机制层第一步——见 [[叠加与多义]]。

### 四层手段

- [[行为层扰动]]：遮挡、反事实、一致性回归，免权重做回归测试；
- [[线性探针]]：逐层曲线 + 随机对照（selectivity），读出 ≠ 使用 [[7]](#ref-7)；
- [[稀疏自编码]]：ReLU+L1 → k-sparse（1600 万维/400 亿 token [[4]](#ref-4)）→ JumpReLU [[9]](#ref-9) 与 Gemma Scope [[10]](#ref-10)，四指标缺一不可、随机基线必须 [[11]](#ref-11)；
- [[降维与激活引导]]：PCA/t-SNE/UMAP 三铁律，方向平移把 TruthfulQA 从 32.5% 提到 65.1% [[12]](#ref-12) [[13]](#ref-13)；
- [[电路追踪]]：CLT 替换 MLP 画归因图，保真度约五成、约 3000 万特征 [[6]](#ref-6) [[14]](#ref-14)；
- [[过程审计]]：轨迹日志 + 动作概率 + 分级审批 + 意图监测，最该先做【推导】。

### 评估与选型

[[可解释性验证与局限]]：观测加干预闭环（替换/消融/引导一致才成立）、三类局限（覆盖上限/解释脱节/开放问题 [[15]](#ref-15)）；[[可解释性落地选型]]：周级日志引用、月级扰动回归、研究级 SAE 与电路，反模式是拿注意力热力图充机制解释 [[16]](#ref-16)。七类手段总表见 [[可解释性方法对比]]。
