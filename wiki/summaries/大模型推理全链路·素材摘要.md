# 大模型推理全链路·素材摘要

## 核心要点

大语言模型的推理过程是一条 **"文本→token→向量→多层 Transformer→概率采样→自回归循环"** 的流水线，按执行顺序拆解六个核心环节。

## 六环节速查

| 环节 | 核心机制 | 关键细节 |
|---|---|---|
| **Tokenizer** | BPE/Unigram/WordPiece | 模型只处理 ID 序列，从未见过"文字"本身 |
| **Embedding + 位置编码** | 查找矩阵 + RoPE | RoPE 使注意力得分仅依赖相对位置差 |
| **多层 Transformer** | Pre-Norm 残差 + SwiGLU FFN | FFN 占 2/3 参数，承担知识存储 |
| **Prefill/Decode** | 并行 vs 串行 | Prefill 计算密集、Decode 访存密集 |
| **KV Cache** | 缓存历史 K/V | 显存 = 2 × 层 × 序列 × KV头 × head_dim × 字节 |
| **采样解码** | Greedy/T/Top-K/Top-P | 实践组合使用 + repetition penalty |

## KV Cache 显存实例

- Llama-2-7B（FP16, 4K）：~2 GB，batch=8 → 16 GB
- Llama-3-8B（FP16, 128K）：~16 GB，逼近消费级 GPU 上限

## 生产级优化方向

- **GQA/MQA**：压缩 KV 头数
- **PagedAttention**：分页管理显存
- **Chunked Prefill**：切块分批计算长 prompt
- **Continuous Batching**：动态插入/移除请求
- **投机解码**：小模型起草 + 大模型验证
