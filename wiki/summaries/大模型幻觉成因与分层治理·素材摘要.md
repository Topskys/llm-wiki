| 主题 | 要点 | 落点页面 |
|---|---|---|

| 表征 | 幻觉与正确回答字面同构，用户难以凭表面判断 | [[大模型幻觉定义与本质]] |

| 三套口径 | Huang 二分 / Zhang 三分（+对齐性）/ Ji 二分（+内部忠实性）；事实性一侧对齐 | [[幻觉分类三套口径对比]] |
| 归因 | Prompt Sensitivity vs Model Variability；改写后消失→提示词，持续→模型 | [[幻觉归因提示词与模型分诊]] |
| 成因四条线 | 数据偏差 / 采样随机性 / 知识截止 / 压缩失真；分属不同环节，无单一银弹 | [[幻觉成因四条线]] |
| SFT 隐蔽点 | 指令微调教出「永远给像样答案」的行为模式 | [[幻觉成因四条线]]、拒答训练 |
| 压缩失真 | 参数容量有限，长尾细节被插值——本文概括，非引自文献 | [[幻觉成因四条线]] |
| 机理 | T=0 只切断采样扰动，切不断分布偏差；贪心确定性输出错误答案 | [[温度归零不消除系统性幻觉]] |
| 检测三路径 | SelfCheckGPT（在线采样一致性）/ FActScore（离线原子分解）/ CoVe（流程内自校验）；互不替代 | [[幻觉检测三条路径]] |
| 三层治理 | 训练层治根 / 推理层止血 / 系统层兜底；层间互补，无单一银弹 | [[幻觉三层治理框架]] |
| 拒答训练 | 训练层性价比最高的一项；不新增知识，只加「不知道」这个合法选项 | 拒答训练 |
| RAG 边界 | 补知识截止，不自动解决忠实性；检索解决「没听说过」不解决「答非所问」 | [[RAG幻觉治理边界]] |
| 工程避坑 | 六条：温度不是治理手段、先归因、RAG 边界、检测成本前置、拒答权衡、层间不可互换 | [[大模型幻觉治理实践]] |
