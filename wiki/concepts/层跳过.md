# 层跳过

## 核心结论

层跳过（Layer Skip）是动态深度的另一支：对简单样本绕过部分层的执行，与 [[早退]] 的差别在于它是「绕过」而非「提前终止」，不要求中间分类器。代表方法 Mixture-of-Depth（MoD）用路由器让多数 token 走浅路径，实测总计算量下降而性能持平 [[2]](#ref-2)。

## 要点拆解

### 与早退的本质差异

| | 早退 | 层跳过 |
|---|---|---|
| 动作 | 提前终止后续计算 | 绕过指定层 |
| 中间分类器 | 需要 | 不需要 |
| 计算流形态 | 深度不齐的截断 | 同层级的稀疏执行 |

「不要求中间分类器」是工程上的关键简化——分类器本身就是一层额外计算与训练负担，MoD 用轻量路由决策取而代之 [[2]](#ref-2)。

### MoD 机制

路由器为每个 token 决定走全层计算还是浅路径：多数 token（通常靠后的虚词与诗意内容）浅路径通过，少数关键 token 走满层。总计算量下降而基准性能持平，前提是路由决策足够准——路由失准的表现即 [[自适应失效模式]] 页的静默掉点。

### 工程影响

跳层破坏静态 batching 与 KV Cache 的规整性——不同样本走过不同层数，推理服务的批处理与缓存假设被打破，论文加速比在真实服务上通常减半（详见 [[自适应失效模式]]）。
