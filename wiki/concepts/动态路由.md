# 动态路由

## 核心结论

动态路由按输入决定激活哪些子模块。混合专家（MoE）的路由网络为每个 token 选择少量专家，Switch Transformers 采用 Top-1 路由 [[3]](#ref-3)，后续变体使用 Top-2 或 Top-k；另有两支衍生路线——按推理深度分层路由的深度特化 MoE，与不确定性高时激活更多专家的置信度自适应路由。核心挑战是负载均衡与路由训练稳定性。MoE 严格说改变的是宽度而非深度，但与 [[早退]] 共享「按 token 分配算力」的内核。

## 要点拆解

### 路由形式谱系

| 路由 | 每激活专家数 | 特点 |
|---|---|---|
| Top-1 | 1 | Switch 的核心贡献，省跨卡通信，容量上限略低 |
| Top-2 / Top-k | 少量 | 表达力更强，通信与算力开销更大 |
| 深度特化 MoE | 分层路由 | 按推理深度分派专家，衍生路线 |
| 置信度自适应路由 | 不定 | 不确定性高时激活更多专家，衍生路线 |

### 动宽度 vs 动深度

早退与层跳过动的是深度（走少几层），MoE 动的是宽度（同层走不同子模块），两者正交但共享「难度感知、按 token 分配」的内核——这也使 MoE 与早退类方法可叠加设计【推导】。MoE 专题细节见 [[MoE混合专家模型总览]]，宽窄权衡见 [[MoE与稠密模型对比]]。

### 核心挑战

- **负载均衡**：路由坍缩使少数专家独占流量，需要均衡损失约束（训练期均衡手段不保证线上分布）；
- **路由训练稳定性**：路由决策不可导，训练期间的探索与收敛是稳定性主要风险。
