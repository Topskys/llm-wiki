# 句向量与池化策略

## 核心结论

Transformer 输出的是 token 级向量序列，句子级向量需要池化得到：CLS pooling 是原始 BERT 的设计但未经任务微调效果差，mean pooling 稳健常用（经典 E5 官方所用），last-token pooling 是指令微调的生成式底座（如 e5-mistral、LLM2Vec）采用的方式，二者不可混淆。代表工作为 Sentence-BERT [[11]](#ref-11) 与 SimCSE [[12]](#ref-12)。

## 要点拆解

### 三种池化策略

| 池化策略 | 做法 | 说明 |
|---|---|---|
| CLS pooling | 取首个 `[CLS]` token 的向量 | 原始 BERT 的设计，未经任务微调时效果差 |
| Mean pooling | 平均所有 token 向量 | 稳健常用，多数句向量模型的默认选择 |
| Last-token pooling | 取最后一个 token | 生成式 LLM 底座句向量常用（如 e5-mistral） |

注意：经典 E5（large/base 档）官方使用 mean pooling，last-token 是指令微调的生成式底座采用的方式，两者不可混淆。

### 代表工作

- **Sentence-BERT**：孪生网络结构，使句向量可高效预计算，适合大规模检索 [[11]](#ref-11)；
- **SimCSE**：用对比学习训练句向量——拉近正样本对、推远负样本对 [[12]](#ref-12)；同源思想 SimCLR 在视觉域并行发展 [[12]](#ref-12)；
- **中文场景**：BGE、M3E、text2vec。
