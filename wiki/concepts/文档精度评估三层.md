# 文档精度评估三层

## 简介

衡量文档智能解析/理解效果需**分三层指标**，与 [[文档智能]] 的能力阶梯对应。字段级错误（如发票总额抽错）的杀伤力远大于字符级错误，因此三层必须配合使用。

## 三层指标

| 层 | 指标 | 对应能力 | 说明 |
|---|---|---|---|
| 字符层 | CER / WER | [[OCR文档解析]] | 字符/词错误率，衡量识别准不准 |
| 结构层 | TEDS / CDM / mAP | [[表格结构还原]]、[[公式识别]] | 表格 TEDS、公式 CDM、版面 mAP，衡量结构还原对不对 |
| 语义层 | 字段 F1 / STP | 理解段 | 衡量字段级业务正确性（如金额、税号） |

- 字符层对应 L0 字符层：CER 可低于 1%（印刷体），但救不了字段级错误。
- 结构层：[[公式识别]] 用 CDM（Character Detection Matching）衡量"视觉是否正确"，比编辑距离贴近真实；[[表格结构还原]] 用 TEDS 衡量结构相似度。
- 语义层：字段 F1 / STP 最贴近业务价值，但也最难标定。

## 四个陷阱

1. **基准≠业务**：公共基准（如 [[OmniDocBench]]）精度高不代表真实业务命中率高，两者口径不同。
2. **字符掩盖字段**：字符准确率 99%，但字段提取错误仍直接致经济损失——单一字符指标会掩盖字段级问题（呼应 [[OCR文档解析]] 的语义缺失）。
3. **单一指标失真**：只看一个指标会片面对齐到该指标，忽略其他维度。
4. **静态基准饱和**：公开基准因公开而趋于饱和、区分度下降，需动态更新。

## 与校验互补

离线评估（scale 层指标）与 [[文档智能校验三支柱]]（业务侧置信度/溯源/规则）互补：评估解决"模型整体准不准"，校验解决"这一条数据可不可信"。
