# Agent最小权利与审批门

## 核心结论

- 权限控制的两维模型：**操作可逆性**（可逆/难逆/不可逆）× **爆炸半径**（窄/宽/全系统），交叉界定授权门槛。
- 不可逆或高影响操作**强制人工审批**——审批门由四要素构成：决策者、进行中状态、路由与持久记录。
- 与 [[四档沙箱隔离模型]] 共同构成隔离层：沙箱管代码执行边界，权限管操作授权边界。

## 两维权限模型

| | 窄半径（单文件） | 宽半径（多服务） | 全系统（无边界） |
|---|---|---|---|
| **可逆** | 自动 | 自动+审计 | 暂停+确认 |
| **难逆** | 自动+审计 | 审批门 | 审批门 |
| **不可逆** | 审批门 | 审批门 | 人工审核 |

## 审批门四要素

1. **决策者**（谁允许）；
2. **进行中状态**（等待中/已批准/已拒绝）；
3. **路由**（把请求交给有权限批准的人）；
4. **持久记录**（审计追踪）。

## 要点拆解

- 撤销权限：**用完即收**——一次性凭证（如 `EPHEMERAL_TOKEN`）用完即撤销，最小化凭证有效期。
- 沙箱内的绕过审批只有在 sandbox 边界之后才可接受：沙箱内不应有生产凭证、共享状态写权限或通往关键系统的网络路径。
