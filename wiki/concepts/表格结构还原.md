# 表格结构还原

## 简介

表格的二维结构无法用序列表达，这是它比线性文本困难的根源。表格结构还原由 [[文档智能]] 解析段承接，目标是还原出行列与合并单元格。

## 四阶段

```mermaid
flowchart LR
    A["① 区域检测<br/>Faster R-CNN / YOLO<br/>从版面中定位表格"] --> B["② 结构识别<br/>Transformer 自注意力<br/>GNN 单元格关系推理<br/>解析行列与合并单元格"]
    B --> C["③ 内容识别<br/>对每个单元格<br/>调用 OCR 识别文本"]
    C --> D["④ 还原输出<br/>Excel · JSON · HTML<br/>单元格级坐标溯源"]
    style A fill:#E9F4F5,stroke:#117C88
    style B fill:#E9F4F5,stroke:#117C88
    style C fill:#E9F4F5,stroke:#117C88
    style D fill:#117C88,color:#fff,stroke:#0A5A63
```

- **区域检测**：从版面定位表格（承接 [[版面分析]]）。
- **结构识别**：解析行列与合并单元格坐标，主流用 Transformer 自注意力或 GNN 推理单元格关系。
- **内容识别**：逐格调用 [[OCR文档解析]] 识别文本。
- **还原输出**：将结果填回结构，输出 Excel / JSON / HTML，支持单元格级坐标溯源（溯源见 [[文档智能校验三支柱]]）。

## 难点谱系

| 表格类型 | 难点 |
|---|---|
| 有线表 | 表格线断裂、印章干扰 |
| 无线表 | 无边界，靠文本空间分布与语义特征推断单元格边界（**最难**） |
| 异形表 | 多级表头、跨行跨列的不规则合并 |
| 跨页表 | 需通过语义与版式双特征判断前后页连续性 |
| 旋转表 | 倾斜或旋转需先校正 |

商用服务对无线表、嵌套表等难例的效果已优于早期版本，并能在一定程度上规避印章干扰与表格线断裂。

## 关键技术

### TableFormer（CVPR 2022）

用 Transformer 直接预测表格结构，**不依赖 OCR 结果**，是 [[Docling]] 的表格引擎——价值在于切断"OCR 错则结构也错"的级联。自 1.16.0 起分 `FAST`（更快、准确率较低）与 `ACCURATE`（默认，处理复杂表格）两档。

### 两阶段解耦

先结构后内容，避免结构判断被内容误差污染。Docling 的 `do_cell_matching` 开关可选"结构映射回 PDF 单元格"或"用结构预测的文本单元格"；多列被错误合并为一列时关闭它可改善。
