# 权限元数据绑定

## 核心结论

- **目标**：确保每个 Chunk 均携带权限信息，检索时不丢失。
- **关键**：每个 Chunk 必须继承原文档的权限元数据，向量与 metadata 一并存入向量数据库。
- **坑点**：只在文档层存权限而 Chunk 不带权限，检索召回的切片将丢失权限属性，直接越权。

## 要点拆解

### 权限标签维度
- 租户 ID（tenant_id）
- 部门 ID（dept_id）
- 角色列表（roles）
- 用户白名单（whitelist）
- 文档密级（classification）

### 代码示例
```python
doc_metadata = {
    "tenant_id": "t_123",
    "dept_id": "dept_hr",
    "roles": ["hr_manager", "hr_staff"],
    "whitelist": ["user_001"],
    "classification": "internal"
}

for chunk in split_document(document):
    vector = encoding_model.encode(chunk.text)
    vector_db.insert(
        vector=vector,
        metadata={**doc_metadata, "chunk_id": chunk.id, "doc_id": doc.id}
    )
```
