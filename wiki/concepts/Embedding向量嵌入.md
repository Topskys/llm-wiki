# Embedding向量嵌入

## 核心结论

- **Embedding（嵌入向量）**：把非结构化数据（文本、图片、音频、视频）通过模型转换成**一段固定长度的浮点数数组**（如 768 维、1536 维）。
- **核心思想**：语义相近的内容，在向量空间里距离更近。
- **向量无人类可读含义**：每一维度代表语义特征，模型学到的知识被编码进这些数字；检索时不是关键词匹配，而是计算余弦相似度、欧氏距离等相似度。

## 例子

| 文本 | 向量空间表现 |
|------|-------------|
| 苹果很好吃 | 输出向量 [0.12, -0.34, 0.56, ...] |
| 水果苹果味道不错 | 与上面距离很近（语义相似） |
| 手机苹果性能很强 | 与上面距离远（语义不同） |

## 要点拆解

- 一句话总结：把内容翻译成向量空间里的坐标，方便计算机衡量语义相似度。
- 在 RAG 链路上的位置：文档 → 切分 chunk → Embedding 模型转向量 → 存入向量库；用户提问 → 问题转向量 → 向量库检索 TopN 相似文档 → 把文档丢给 LLM 生成答案。
- 与检索优化的关系：Embedding 质量直接决定 Dense 召回上限，在线调优多做于索引与 rerank 侧补救。→ [[Hybrid混合检索]]
