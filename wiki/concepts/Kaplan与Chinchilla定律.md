# Kaplan 与 Chinchilla 定律

## 核心结论

Kaplan 定律主张新算力优先投参数，「参数大者为王」定了此后两年的路线——顺着它训出的 GPT-3 [[2]](#ref-2)，按后来标准只喂到最优配比的十分之一左右【推导】。两年后 Hoffmann 等人给出 Chinchilla 修正：参数与数据等比例增长，相近总算力下四分之一大小的 70B 模型配数倍数据全面胜过 280B 的 Gopher [[4]](#ref-4)，行业随即开始核算自家旗舰的欠训。2024 年的调和研究证明两家分歧的主因是参数口径而非方法错误 [[3]](#ref-3)。

## 要点拆解

### 两代定律对照

| 维度 | Kaplan（2020） | Chinchilla（2022） |
|---|---|---|
| 来源 | OpenAI [[1]](#ref-1) | DeepMind [[4]](#ref-4) |
| 参数口径 | 非嵌入参数 | 总参数 |
| 最优参数 | N_opt ∝ C^0.73 | N_opt ∝ C^0.50 |
| 最优数据 | 慢于参数增长 | 与参数等比例 |
| 最优 token/参数比 | 未给中心值 | 约 20 |
| 代表模型 | GPT-3（175B/300B，后被判定欠训） | Chinchilla（70B/1.4T） |
| 核心主张 | 参数大者为王 | 数据配比定生死 |

### 分歧与调和

- **参数口径是主因**：Kaplan 统计的是非嵌入参数（不含嵌入层与输出投影），而这两部分受词表大小影响很大。2024 年 Pearce 与 Song 的调和论文 [[3]](#ref-3) 显示：换回总参数口径在小尺度模拟得 0.51，与 Chinchilla 的 0.50 吻合；而按非嵌入口径做小尺度局部拟合得约 0.78，接近 Kaplan 的 0.73——**偏差来自口径与小尺度分析，而非方法错误**；
- **辅证三因素**：Porian 等人独立调和，指出末层计算成本、warmup 时长、优化器跨规模调参三个因素同样有影响，修正后与 Chinchilla 高度一致 [[5]](#ref-5)；Epoch AI 的 Besiroglu 等人复现修正了 Chinchilla 的拟合，最优 token/参数比略有上移 [[6]](#ref-6)；
- **两条教训**：引用任何 scaling 数字，先问参数怎么数的；对经验拟合而言，条件即结论。此后发表的 scaling 研究都明确注明口径、调度与拟合方法。

### 两条产业路线

修正之后，头部实验室走向两种站位，本质是对同一曲线不同位置的押注：

- **OpenAI 系·上限优先**：偏向大参数强模型，训练与推理都贵，赌的是前沿能力溢价；
- **LLaMA 系·推理侧摊销**：把账算到推理侧，小参数模型主动超额喂数据（over-training），训练贵一点换推理便宜——Llama 3 的 8B 用约 15T token 训练，约是 Chinchilla 配比的百倍【推导】，405B 版本花了约 3090 万 H100 GPU 小时 [[7]](#ref-7)。

两条路都对，因为优化的目标函数不同：一个最小化前沿能力差距，一个最小化「训练加推理」的总拥有成本。**规模定律给出的是曲线，站在曲线哪个位置经营，是商业决策**。
