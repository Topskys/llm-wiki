# 上下文最小化

## 核心结论

- **目标**：缩减敏感数据暴露面。
- **做法**：召回后执行二次权限校验（兜底），仅将回答所需的必要片段送入 LLM 上下文。
- **原则**：不把完整大文档全部塞给 LLM。

## 要点拆解

### 二次校验
即使检索层已做前置过滤，仍对召回结果执行二次权限校验，作为防御纵深。

### 代码示例
```python
authorized_chunks = [c for c in results if check_permission(c, user)]
context = build_context(authorized_chunks, max_tokens=2000)
```
