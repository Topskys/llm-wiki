# 数字居民

## 核心结论

数字居民是沙盒社会的原子单元：每个智能体当成一个「数字居民」，给它身份画像、记忆、目标与社交能力，放进可配置环境里自主生活。智能体层的五件套（画像、记忆、规划、行动、反思）决定「居民像不像人」，行为来源从研究者写死的 if-else 变成模型基于记忆与目标的生成式决策 [[1]](#ref-1)。

## 要点拆解

### 五件套构成

- **画像 Profile**：给身份，确定居民「是谁」；
- **记忆 Memory**：给连续性，让今天的经历影响明天的行为；
- **规划 Planning**：给主动性，产生目标驱动的日程与行动；
- **行动 Action**：对环境与他人施加影响；
- **反思 Reflection**：把经历沉淀成稳定态度，是行为从「逐次反应」升级为「有立场」的关键。

### 与规则智能体的分野

传统 ABS 的行为上限是「复现已知规律」，脚本只能覆盖设计者想到的情形；数字居民的行为由生成式决策产生，可涌现未预期的群体现象，这是 [[传统ABS与LLM沙盒对比]] 的核心差异项。

### 与多 Agent 上下文管理的关系

五件套里记忆与反思的工程实现，直接复用多 Agent 系统的上下文管理结论：上下文继承、注入还是引用机制的选择，决定大规模下记忆一致性与成本 [[多Agent上下文传递方式对比]]。
