# MCP 安全最佳实践

## 核心结论

MCP 协议本身不强制实现安全机制，安全边界与权限控制需由 Host 与 Server 共同落地。

## 六条原则

| 原则 | 说明 |
|------|------|
| **最小权限** | 仅授予任务执行所需的最低权限，只读场景不开放写入 |
| **高风险确认** | 数据修改、消息发送、资源删除等操作必须用户确认 |
| **凭证隔离** | 认证密钥由 Client/Server 层独立管理，严禁传入 LLM 上下文 |
| **输入校验** | 工具调用参数严格校验与清洗，防范 Prompt Injection |
| **全链路审计** | 记录调用主体、目标 Server、工具、参数、结果、时间 |
| **沙箱隔离** | 代码/文件操作类工具运行在独立沙箱环境中 |
