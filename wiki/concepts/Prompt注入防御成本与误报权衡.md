# Prompt 注入防御成本与误报权衡

## 核心结论

- 防御强度与延迟/效用呈**非线性权衡**——CaMeL 用约 7pp 效用换取"可证明安全"，SecAlign 是当前"低效用损失 + 低 ASR"的最优点，双 LLM 架构付出约 2 倍 token 成本换取结构性隔离。
- 误报的真实代价：过度拦截会把合法内容判为攻击；HITL 审批在人审疲劳下会退化为橡皮图章。

## 八措施成本与效果全景

| 防御措施 | 延迟/成本开销 | 效用影响 | 安全效果 | 已知短板 |
|---|---|---|---|---|
| 输入正则/黑名单 | +0～5ms | ≈0 | 仅拦已知模式 | 变体秒级绕过 |
| Spotlighting/自提醒包裹 | 约 3× 单次调用延迟与成本 | 轻微 | 显著降低注入生效率 | 依赖提示设计，仍可被覆盖 |
| 分类器护栏（LLM Guard 等） | +50～200ms/次 | ≈0 | 中等 | 每次护栏调用都加延迟 |
| StruQ | 训练侧，推理零开销 | Mistral-7B 持平，Llama3-8B 降约 4.5% | 优化类攻击 ASR 降至 ≈0 | **对优化攻击仍脆弱（27%/45% ASR）** |
| SecAlign | 训练侧，推理零开销 | **无显著效用损失** | 最强注入 ASR 降至 **1%/8%** | 需重训/微调权限 |
| Task Shield | 每次工具调用 +1 次 LLM 评估 | AgentDojo 效用 69.79% | ASR 2.07% | 高频调用场景延迟敏感 |
| 双 LLM / 隔离 LLM | 约 2× token 与延迟成本 | 摘要保真度损失 | 结构性切断注入→工具路径 | 复杂任务需两段规划 |
| CaMeL | 插桩 + 双模型解析 | AgentDojo **77% vs 84%（-7pp）** | **可证明安全** | 集成复杂度最高 |

## 三条实操决策原则

1. **分层路由**：确定性检查内联处理 90% 常规流量；只有可疑输入才升级到 LLM 分类器或人审。
2. **训练侧优先**：SecAlign/Meta-SecAlign 已开源且效用损失最小，具备微调能力的团队应把预算投在训练侧。
3. **影子模式先行**：新护栏先以旁路模式跑 2–4 周统计误报率，低于阈值再切强制执行。
