# 提示词注入

## 核心结论

- 提示词注入（Prompt Injection）是 LLM 应用最严峻的安全挑战，OWASP Top 10 for LLM Applications 2025 将其列为 **LLM01 头号风险**[[1]](#ref-1)。
- 根因是 LLM 在架构上**无法根本区分"指令"与"数据"**——外部数据与系统指令共同拼入上下文，注入天然存在。
- 对 Agent 威胁最大的是**间接注入**：恶意指令隐藏在网页/文档/邮件等外部数据中，可劫持 Agent 通过工具调用产生真实世界副作用。
- 2025 年 12 月 OpenAI 公开承认 Prompt 注入"不可能被彻底解决"[[3]](#ref-3)——这为"假设注入已发生、压缩影响面"的防御路线提供了产业界背书。

## 注入 vs 越狱

| 维度 | Prompt 注入 | 越狱 |
|---|---|---|
| 攻击目标 | 应用逻辑、数据、权限 | 模型的安全对齐与内容策略 |
| 典型后果 | 数据外泄、误调用工具 | 生成有害/违禁内容 |
| 责任主体 | 应用开发者 | 模型厂商 + 应用方 |
| 防御重心 | 架构与权限 | 对齐训练 + 内容过滤 |

## 四类攻击载体

- **直接注入**：用户输入中夹带指令，多语言/低资源语言可大幅降低拒绝率[[2]](#ref-2)。
- **间接注入**：恶意指令嵌入 Agent 会读取的外部数据（网页/邮件/文档/工具返回），RAG 文档检测难度**极高**。
- **多模态注入**：恶意指令嵌入图像，低对比度文字人类无法察觉但视觉语言模型可解析。
- **Agent 工具滥用**：注入不再只是"说错话"，而可能变成发邮件、转账、删文件、执行命令。

## Agent 场景的独特风险

Agent 具备**自主规划**与**工具调用**能力，一旦被注入，攻击者不仅能窃取信息，还能通过工具链产生**真实世界副作用**。因此 Agent 防御核心是**在架构层面假设注入终将发生**，通过隔离、权限最小化与执行管控，让被劫持的 Agent 也无法造成实质性破坏。
