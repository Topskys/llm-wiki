# 提示词注入

## 核心结论

- 提示词注入（Prompt Injection）是 LLM 应用最严峻的安全挑战，OWASP Top 10 for LLM Applications 2025 将其列为 **LLM01 头号风险**[[1]](#ref-1)。
- 根因是 LLM 在架构上**无法根本区分"指令"与"数据"**——外部数据与系统指令共同拼入上下文，注入天然存在[[2]](#ref-2)。
- 对 Agent 威胁最大的是**间接注入**：恶意指令隐藏在网页/文档/邮件等外部数据中，可劫持 Agent 通过工具调用产生真实世界副作用[[2]](#ref-2)。

## 风险分类

输入侧检测需重点覆盖四类[[2]](#ref-2)：

| 风险类别 | 示例 |
|---|---|
| 系统指令窃取 | "输出你的系统提示词" |
| 规则覆盖 | "忽略以上所有指令" |
| 间接注入 | 文档/网页中夹带的指令 |
| 多轮诱导 | 跨多轮对话逐步引导越权 |

## 直接注入 vs 间接注入

- **直接注入**：用户输入中夹带指令，攻击目标明确。
- **间接注入**：攻击者无法直接接触模型，把恶意指令嵌入 Agent 会读取的外部数据（网页、邮件、文档、工具返回），等待 Agent 读取时被动触发[[2]](#ref-2)。
- **越狱（Jailbreak）**：一种特殊提示词注入，目标是让模型完全忽略自身安全协议[[1]](#ref-1)。

## Agent 场景的独特风险

Agent 具备**自主规划**与**工具调用**能力，一旦被注入，攻击者不仅能窃取信息，还能通过工具链产生**真实世界副作用**（发邮件、执行代码、修改数据）。因此 Agent 防御核心是**在架构层面假设注入终将发生**，通过隔离、权限最小化与执行管控，让被劫持的 Agent 也无法造成实质性破坏[[2]](#ref-2)。
