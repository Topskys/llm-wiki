# 缓存隔离

## 核心结论

- **目标**：防止跨用户缓存泄露。
- **做法**：缓存 Key 必须绑定用户身份和权限标签。
- **原则**：用户 A 的缓存结果不可直接返回给用户 B。

## 要点拆解

### 代码示例
```python
cache_key = f"rag:answer:{user.id}:{','.join(user.roles)}:{hash(query)}"
cached = cache.get(cache_key)
if cached:
    return cached

response = generate_answer(results)
cache.set(cache_key, response, ttl=3600)
return response
```

### 与权限变更传播的关系
当用户权限变更时，需失效相关缓存。参见 [[RAG权限隔离生产实践]] 中的权限变更传播机制。
