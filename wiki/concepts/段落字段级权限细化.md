# 段落字段级权限细化

## 核心结论

- **目标**：同一文档内不同段落或字段设置差异化权限。
- **做法**：元数据 schema 增加 section_id 和 field_name 维度，入库时按段落/字段独立标注权限。
- **代价**：元数据膨胀和过滤复杂度上升。

## 要点拆解

### 元数据 schema 扩展
```python
chunk_metadata = {
    "doc_id": "doc_123",
    "section_id": "sec_4",
    "field_name": "salary",
    "tenant_id": "t_123",
    "dept_id": "dept_hr",
    "roles": ["hr_manager"],
    "classification": "confidential"
}
```

### 典型场景
- 员工档案：基本信息全员可见，薪资字段仅 HR 可见
- 合同文档：甲方法务条款仅甲方可见，乙方法务条款仅乙方可见
