# 公式识别

## 简介

公式识别把二维数学结构序列化为 LaTeX 或 MathML，难点随复杂度非线性上升，属于 [[文档智能]] 解析段的结构层。

## 四类形态

| 形态 | 特征 |
|---|---|
| 行内公式 inline | 嵌在正文流中，需与文字正确分离 |
| 行间公式 display | 独立成块，通常居中并带编号 |
| 复杂结构 | 多行对齐、矩阵、分段函数、上下标嵌套 |
| 混排公式 | 中英文混排、公式内嵌中文 |

## 代表方案

| 方案 | 定位 | 特点 |
|---|---|---|
| UniMERNet | 专用模型 | 面向真实场景数学表达式识别 |
| 文档 VLM | 端到端 | 公式作为内容块直接输出 LaTeX（见 [[文档VLM三大范式]]） |
| pix2tex | 轻量方案 | 复杂公式表现弱 |

## 评测：CDM 优于编辑距离

评测用 **CDM**（Character Detection Matching），比纯编辑距离更贴近"公式是否**视觉正确**"。编辑距离会把结构正确但符号顺序不同的公式判错，CDM 则通过字符检测匹配衡量渲染一致性。

OmniDocBench 同时采用 `display_formula_Edit_dist` 与 `display_formula_CDM` 两项指标（见 [[OmniDocBench]] 与 [[文档精度评估三层]]）。

MinerU 2.5 把复杂长公式与中英混排公式的准确解析列为其相对 2.0 的核心改进（见 [[MinerU]]）。
