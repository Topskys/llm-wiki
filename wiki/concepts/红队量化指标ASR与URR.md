# 红队量化指标ASR与URR

## 核心结论

- **红队产出必须转化为可比较、可回归、可追踪的数字**，才能作为模型发布与部署的硬性门禁；[[HarmBench]] 统一了攻击方法分类、目标行为分类学与指标定义[[6]](#ref-6)。
- 四类核心指标中，ASR/TGR 衡量「有多容易被攻破或生成有害内容」（越低越好），URR 衡量「是否因防御过严而误伤良性请求」（越低越好），DFR 衡量「危险能否被检出」（越高越好）。
- 工程上三个要点：多基准报告而非单点数字、**ASR 与 URR 需联合优化而非单边压低**、判官本身也要校准与对抗鲁棒性测试。

## 指标定义

| 指标 | 形式化定义 | 判读方向 |
|---|---|---|
| 攻击成功率 ASR | $$ASR = \frac{\#\text{成功诱导有害输出}}{\#\text{总攻击样本}}$$ | 越低越好 |
| 过度拒绝率 URR | $$URR = \frac{\#\text{对良性请求的误拒}}{\#\text{良性测试集}}$$ | 越低越好 |
| 毒性生成率 TGR | $$TGR = \frac{\#\text{被判为有毒的输出}}{\#\text{总生成样本}}$$ | 越低越好 |
| 失败检测率 DFR | 在重复采样或分布内–分布外对照实验中统计，无统一闭式公式 | 越高越好 |

## 工程实践三要点

1. **多基准报告而非单点数字**：不同基准对攻击强度的刻画差异显著，单一基准的优异成绩无法外推为整体安全水平，需在多基准、多温度、多采样下联合报告[[6]](#ref-6)。
2. **ASR 与 URR 的权衡**：更严格的拒绝策略压低 ASR 的同时会推高 URR、损害可用性，二者需联合优化而非单边压低。
3. **判官自身的可靠性**：用 LLM 自动判定攻击是否成功时，判官也可能被对抗样本操纵，需对其校准并做对抗鲁棒性测试。
