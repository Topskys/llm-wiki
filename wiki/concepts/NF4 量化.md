# NF4 量化

## 核心结论

NF4（4-bit NormalFloat）是 QLoRA 微调方案的核心数据类型：神经网络权重近似服从零均值正态分布，普通 INT4 的均匀网格与实际分布不匹配 [[5]](#ref-5)；NF4 把 16 个量化点放置在标准正态分布的分位点上，靠近 0 处密、远 0 处稀，理论上是正态分布下信息论最优的 4-bit 格式。在冻结的 NF4 基座上插入可训练的 LoRA 适配器，单卡 48 GB 即可微调 65B 模型且不掉精度（QLoRA 方案），是 HuggingFace 生态最主流的 LLM 微调路径之一 [[5]](#ref-5)。

## 要点拆解

### 分布匹配的码本

普通 INT4 假设数据均匀分布，对正态权重一半网格点浪费在尾部、中心区域取样不足；NF4 的分位点码本让每个 code 承载等概率的区间，同 4 bit 装下更多有效信息【推导】。

### 三件配套技术

- **NF4 量化**基座；
- **双重量化**：对每 64 权重共享的 FP32 scale 再做一次 INT8 量化，额外节省约 0.37 bit/权重 [[5]](#ref-5)；
- **分页优化器**：通过统一内存把 Adam 优化器状态按需分页到 CPU，避免长序列训练时的显存溢出 [[5]](#ref-5)。

### 使用边界

NF4 主要用于微调而非纯推理部署，纯推理场景更常用 GPTQ/AWQ [[5]](#ref-5)。对微调位形的选择逻辑：显存极度紧张且要训练适配器 → QLoRA NF4；只需推理 → W4 weight-only。

### 与 K-quants 的非均匀码本同源

NF4 的分位点码本与 [[K-quants]] 在低比特档对 scale/min 再量化的思路同属「非均匀编码」，而 [[极限低比特量化]] 的格点码本是这条路线的极限形态：都不是均匀网格，只是逼近的分布假设不同【推导】。
