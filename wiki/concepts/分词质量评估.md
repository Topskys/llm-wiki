# 分词质量评估

## 核心结论

衡量分词质量有三个常用指标——碎片化率、压缩比、fertility（生育率），三者都是越低越好，最终还要用下游任务效果验证；分词同时直接决定三笔工程账：上下文窗口按 token 计数、API 计费按 token 单价、推理延迟随序列长度增长，换分词器等于换成本结构。

## 要点拆解

### 三个评价指标

| 指标 | 含义 | 方向 |
|---|---|---|
| 碎片化率（Fragmentation Ratio） | 被切碎的词占全部词的比例 | 越低越好 |
| 压缩比 | 原始文本压到多少 token | 越低越好 |
| fertility（生育率） | 平均每个词产生几个 token | 越低越好 |

三个指标给的是离线体检，最终拍板仍要下游任务效果说了算。

### 与模型成本的三笔账

- **上下文窗口**：按 token 计数，序列越碎可用上下文越短；
- **API 计费**：按 token 单价，同等内容越省 token 越省钱；
- **推理延迟**：随 token 序列长度增长，碎片化直接拖慢响应。

同样的提示词换个分词器，成本与延迟都会随之变化，这是多语言应用选型时最容易忽略的成本项。
