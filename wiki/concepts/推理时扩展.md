# 推理时扩展

## 核心结论

推理时扩展把“更聪明”从一次性训练投入变成可以按请求购买的运行时资源。模型参数与训练数据保持不变，仅在推理阶段按需分配算力，通过延长思维链、重复采样、树搜索或验证器筛选来换取更高质量输出，与预训练扩展、后训练扩展并列，构成第三条扩展轴。

## 要点拆解

### 定义与定位

推理时扩展（test-time scaling，测试时计算扩展）指模型参数与训练数据保持不变，在推理阶段按需投入更多计算，通过延长思维链、重复采样、树搜索或验证器筛选来提升输出质量。它与预训练扩展、后训练扩展并列，差别在于算力不再一次性前置投入，而是按请求单独结算。同一份权重可同时提供快慢两种模式：快模式走单次解码，慢模式走长思维链或多次采样。

认知科学的 System 1（快速直觉）与 System 2（审慎推理）类比说明了推理模型的设计动机：人类不会为 1+1 启动慢思考，而推理模型对每个请求都展开长思维链。

### 瓶颈与突破

标准解码只做一次采样，每个 token 的计算量固定，预算由模型规模与序列长度决定，与题目难易无关。自回归生成每一步都以已生成内容为条件，长链推理里一次早期偏差会被后续 token 反复引用并放大，最终把整题带偏，传统解码没有回溯通道。FLOPs 匹配的对比表明，只要较小模型在题目上已有非平凡成功率，测试时算力就能让它超过参数规模大 14 倍的模型，推理算力可以部分替代参数规模。

### 方法体系

按算力消耗方式，现有方法归入四个方向：

1. **串行扩展**：在一条思维链上写更长的推理 token，中间夹带回溯、自我验证与策略切换。思维链提示首次系统证明在 prompt 里给逐步推理示例就能显著提升复杂推理准确率；o1 把这一思路从提示技巧变成训练目标，用强化学习让模型自发写出长思维链。
2. **并行扩展**：对同一问题独立采样 N 条完整路径，再用外部信号聚合答案。Best-of-N 加验证器为 N 个候选分别打分选最优；Self-Consistency 多数投票用多数投票替代贪心解码，无需外部验证器。
3. **树搜索**：把推理看成状态与动作构成的分支结构，在中间节点剪枝与回溯。Tree of Thoughts 把每个中间想法当作节点；MCTS 加过程奖励模型（PRM）对每一步打分而非只看最终答案。
4. **反思与自适应**：先出草稿再批判修订。Self-Refine 用同一个模型扮演生成器、反馈者与修订者；Reflexion 把语言化反思存进情景记忆。自适应算力分配按题目难度动态分配预算，s1 的 budget forcing 在推理时强制截断思考或追加“Wait”拉长思考。

### 缩放规律

测试时缩放律指出不同方法的有效性随题目难度剧烈变化，不存在对所有 prompt 都最优的单一策略；在小预算下，针对难题的自适应策略能让小模型超过 14 倍大的模型。指数幂律给出覆盖率与采样数的经验关系：$\text{coverage}(x, n) \approx \min\{1,\ \alpha_x \cdot n^{\beta_x}\}$，其中 $\alpha_x$ 与 $\beta_x$ 是与题目难度相关的经验常数。

### 支撑组件

奖励模型按监督粒度分为结果奖励模型（ORM）和过程奖励模型（PRM），PRM 对每个中间步骤给分，在 MATH 上明显优于 ORM。可验证强化学习仅给可验证奖励（如数学答案正确性、单元测试通过率），纯强化学习就能让模型自发出现自我反思、验证与回溯。

### 代表系统

- **o1 系列**：用大规模强化学习训练模型在回答前生成长思维链，并在生成过程中反思与尝试不同策略，在 AIME、Codeforces、GPQA 等难题上表现持续上升。
- **DeepSeek-R1**：管线分四段（冷启动微调→面向推理的强化学习→拒绝采样扩充监督数据第二轮微调→覆盖全场景的强化学习），蒸馏系列证明大模型涌现的长思维链可用 80 万条样本迁移到 1.5B 至 70B 小模型。
- **s1-32B**：基于 Qwen2.5-32B-Instruct，用 s1K 监督微调，通过 budget forcing 用同一套权重调节思考长度。

### 局限与代价

推理 Token 与普通输出 Token 一样占用显存带宽与计算资源，长思考直接推高延迟和单次成本。串行延长推理链的收益不单调，预算越高边际收益衰减越明显，模型还会在延长思考时放弃此前已得到的正确答案，形成过思考。并行扩展与树搜索依赖奖励模型，缺少自动验证器时，多数投票与奖励模型打分在数百个样本后饱和，瓶颈从生成器转到验证器。

### 工程选型

- 先看可验证性：代码、形式化证明与数学题有自动验证器，开放生成与知识检索缺少裁判，收益有限。
- 先并行后串行：Self-Consistency 与 Best-of-N 实现简单、并行度高，适合作为默认方案；串行长思维链上限更高，但通常要配合强化学习训练才稳定。
- 验证器值得投入：PRM800K 可作为冷启动数据，ThinkPRM 这类生成式 PRM 能用极少量过程标签换来更强泛化。
- 按难度分配预算：简单题用短思维链或贪心解码，难题才放开预算，自适应分配比固定预算更省。
- 给思考长度设上限：生产环境用截断或 budget forcing 控制 token 数，并监控过思考带来的准确率回退。
