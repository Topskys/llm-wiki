# 自适应评测要点

## 核心结论

自适应方法的评测认帕累托不认单点：结果层看准确率与 Pass@k，效率层看平均推理 token 数、FLOPs、延迟与能耗，两层必须同时报告才能定位帕累托改善 [[1]](#ref-1)。一个常见误区是更高的最终准确率不等于更强的自适应能力——可能仅来自更多采样或测试时搜索；真正的自适应证据有两类：跨任务自适应看习得的分配策略能否迁移到新问题，任务内自适应看面对新证据时能否修订假设。

## 要点拆解

### 两层报告

| 层 | 指标 | 说明 |
|---|---|---|
| 结果层 | 准确率 / Pass@k | 任务性能不倒退是底线 |
| 效率层 | 平均每样本 FLOPs / 推理 token 数 / 延迟 / 能耗 | 算力省多少是自适应的本职 |

价值判据是把精度—效率权衡曲线向外推的幅度，而非任何单点数字：单看效率可能只是少算而掉精度，单看结果可能是白堆算力。

### 评测误区

更高的最终准确率可能只是并行采样扩展的产物——Best-of-N 类方法靠候选数量换解决率 [[Best-of-N]]，Self-Consistency 走多数投票 [[Self-Consistency]]，它们的收益来自「次数」而不是「分配」；把这类收益记在自适应头上会高估效果。判据核心：算力总量不变时是否分层投放了【推导】。

### 两类有效证据

- **跨任务自适应**：在一个域学到的分配策略迁移到新任务仍有效，说明学的是「分配能力」而非过拟合母任务；
- **任务内自适应**：面对新证据能修订假设（比如更正此前的推理步骤），而不是把首个答案守到底。
