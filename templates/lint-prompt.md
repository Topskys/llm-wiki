# Lint 巡检指令模板

> 使用场景：每周/每两周对全库Wiki做质量体检，排查问题并输出优化建议时使用。

---

## 完整巡检指令（可直接复制使用）

```
你现在是我的知识库质量巡检员，严格遵循《LLM Wiki工作规则（SCHEMA.md）》对全库Wiki执行健康检查。

【巡检范围】
<指定wiki目录路径，或粘贴所有Wiki页面列表>

【检查项】
逐项扫描所有页面，排查以下问题项：

1. 【P0 阻断级】事实错误、观点冲突未标记
   - 页面内容与来源素材不符
   - 存在相互矛盾的表述但未标注「⚠️观点冲突」

2. 【P0 阻断级】元数据严重缺失
   - 缺少 type / created_at / source 任一字段
   - type 取值不在允许范围内（concept/entity/overview/comparison/source_summary/topic/conflict）

3. 【P0 阻断级】created_at 被篡改
   - 对比 shturl.md 日志，页面 created_at 与首次创建记录不符
   - 更新旧页面时错误覆盖了 created_at

4. 【P0 阻断级】source 断链
   - source 指向的页面已被删除或移入 _archive，溯源链路断裂

5. 【P1 重要级】孤儿页面（无入链无出链）
   - 没有任何其他页面链接到本页面
   - 本页面也没有链接到任何其他页面
   - 完全脱离知识网络

6. 【P1 重要级】断链与缺失
   - 文中明确提到的概念、实体、主题，未创建对应Wiki页面
   - 未添加双向链接，使用普通文本而非 [[页面名]]
   - description 字段缺失（应填写1-3句话页面简述）

7. 【P1 重要级】时间格式错误
   - 不符合 YYYY-MM-DD hh:mm:ss

8. 【P2 优化级】结构与质量
   - 内容过于冗余建议拆分
   - 内容高度相关建议合并
   - 主题重要但内容过浅建议深化
   - description 为空、仅复制标题、概括不准确
   - tags标签命名不统一、存在同义标签

【输出要求】
1. 按上述问题项分别输出问题清单，每条包含：页面名称、问题具体描述、修正建议。
2. 按问题严重程度标注优先级：
   - P0（高）：内容矛盾、事实错误、type/created_at/source缺失、created_at被篡改、source断链
   - P1（中）：孤立页面、断链缺失、时间格式错误、description缺失
   - P2（低）：格式不规范、结构优化建议
3. 最后输出整体巡检总结：总页面数、问题页面数、各类问题数量、优先处理建议。
4. 只输出问题与建议，不得自行修改任何Wiki页面内容。
```

---

## 使用说明

- 本地AI插件可直接读取整个wiki文件夹执行扫描。
- 纯文本对话可先提供index页面列表，再针对性读取问题页面。
- 巡检结果人工确认后，再批量执行修正，避免AI误改。
- 修复完成后执行Git提交（type: lint），并追加shturl.md日志。

---

## 修复后验证清单

人工修复完成后，逐项验证：

- [ ] 所有P0问题已修复
- [ ] created_at 未被二次篡改
- [ ] 元数据字段完整、格式正确
- [ ] 孤儿页面已补链或归档
- [ ] 断链已建页面或改为普通文本
- [ ] index.md 已同步更新（归档页面从索引移除）
- [ ] shturl.md 已追加修复记录
- [ ] 已执行 Git 提交（lint: xxx）
