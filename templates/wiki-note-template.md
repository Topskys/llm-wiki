# Wiki 页面模板

> 新建Wiki页面时复制本模板，填写Frontmatter与正文内容。
> 也可配置为 Obsidian Templater 插件模板，自动填充时间戳。

---

## 标准页面模板

```markdown
---
type: concept
source: [[来源双链]]
description: "1-3句话简述本页面核心内容，用于索引预览与AI快速理解"
created_at: 2026-09-05 14:30:00
updated_at: 2026-09-05 14:30:00
tags: []
---

# 页面标题

## 核心结论

（用1-3句话概括本页面最核心的结论或定义）

## 要点拆解

### 1. 要点一

（详细展开）

### 2. 要点二

（详细展开）

### 3. 要点三

（详细展开）

## 相关页面

- [[相关页面1]]：说明与本页面的关联原因
- [[相关页面2]]：说明与本页面的关联原因
- [[相关页面3]]：说明与本页面的关联原因

## 参考来源

- [[来源素材1]]
- [[来源素材2]]
```

## Templater 插件自动模板

> 安装 Templater 插件后，将以下内容保存为模板，可自动填充时间戳与页面标题。

```markdown
---
type: <% tp.system.prompt("页面类型：concept / entity / overview / comparison / source_summary / topic / conflict") %>
source: <% tp.system.prompt("来源双链，格式 [[xxx]]") %>
description: <% tp.system.prompt("页面简述，1-3句话") %>
created_at: <% tp.date.now("YYYY-MM-DD HH:mm:ss") %>
updated_at: <% tp.date.now("YYYY-MM-DD HH:mm:ss") %>
tags: []
---

# <% tp.file.title %>

## 核心结论

## 要点拆解

## 相关页面
- [[ ]]

## 参考来源
```

## 各类型页面写作要点

### concept（概念页）
- 开头给出清晰定义
- 拆解核心原理、机制、组成部分
- 说明适用场景与局限性
- 关联相关概念、对比相近概念

### entity（实体页）
- 开头概括实体是什么（人物/项目/公司/工具）
- 关键信息：背景、核心特点、重要事件/版本
- 关联相关实体、使用的技术概念
- 标注信息时效（实体信息可能随时间变化）

### overview（总览页）
- 提供领域/主题的全局地图
- 梳理发展脉络、核心分支、关键节点
- 链接到下属各概念/实体页面
- 适合作为某一领域的入口页面

### comparison（对比页）
- 开头给出核心差异结论
- 使用表格做多维度横向对比
- 分别说明各自的适用场景与选型建议
- 链接到被对比对象的各自页面

### source_summary（素材摘要页）
- 开头概括素材核心主旨
- 按素材原有结构提炼要点
- 标注素材来源、作者、发布时间
- 链接到由该素材衍生出的概念/实体页面

### topic（主题页）
- 围绕某一主题/专题做综合归纳，可作为该主题的入口
- 汇总关联概念、实体、素材摘要，梳理主题脉络
- 链接到该主题下的各概念/实体页面

### conflict（冲突记录页）
- 开头说明冲突主题与双方立场
- 并列双方表述与依据（保留原文），标注来源
- 记录当前处理状态（待裁决）/ 人工裁决结论

## 更新旧页面注意事项

1. **严禁修改 `created_at`**：这是页面首次创建的永久记录。
2. **必须刷新 `updated_at`**：每次内容修改都更新为当前时间。
3. **同步更新 `description`**：如果页面主旨发生变化，简述也要同步更新。
4. **更新 `source`**：如果新增了来源素材，补充到source字段。
5. **冲突不覆盖**：新信息与旧内容冲突时，标注「⚠️观点冲突」，保留双方表述。
